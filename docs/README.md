# Repository documentation

`docs/` contains static material for people working with this repository. It is not an architecture authority and must not override `vault/ctrl/GOAL.md` or an accepted module ADR.

- `design/` — standalone HTML prototypes and design-token snapshots.
- `reference/` — visual or other reference assets used during implementation.
- `development/` — setup and operator guides for repository development.

Architecture and development governance live under `vault/ctrl/`; runtime truth lives in code, builds, and tests. Superseded project knowledge belongs in `vault/ctrl/history/`, not here.
