Why actions sit on the note

Rewrite, summarise, and translate target the open Resource. Putting them in the conversation would make the user name the target again. Read-only content omits the action bar instead of showing disabled controls.

Local first, web explicit

Local search shows source paths and opens them as Work Resources. Online lookup is a separate button and never runs as a side effect of local search.

History is a projection

Sessions and turns come from the canonical Markdown transcript. Re-run and fork act on that session record; the browser does not become a second transcript authority.

FCT use is an override

Auto is the default. The compact composer selector is the one per-session FCT control; Library is not a prerequisite for ordinary work.

Recovery is part of the surface

Unavailable, stale, conflict, progress, choice, capture, and approval are typed decision kinds. The UI renders owner facts and does not invent targets or outcomes.

No hidden second identity

Projects, notes, applications, and FCTs are explicit Resources or projections for the same Irisy identity. None creates a separate agent or transcript owner.
