1Results stay visible

Artifacts, staged changes, and provenance remain in the center Resource pane instead of disappearing after a modal closes.

2One visible Irisy

The fixed resident composer shows the Irisy identity and its current Resource context. Planning and mutation safety are internal execution policy, not user-selected identities or modes.

3Projects are Work Resources

New Project creates a Project Resource. The displayed path is descriptive context; it does not invent a task-directory authorization model.

4Transcript authority stays singular

Session history is projected from the canonical append-only Markdown transcript. Re-run and Fork remain available without exposing unsupported destructive history controls.

5Review before mutation

A consequential write must show the exact target, staged change, revision precondition, recovery point, and provenance before approval.

6Design evidence is declared

Names, revisions, counts, and outcomes in this static mockup are illustrative. Runtime verification requires executable pipeline evidence.
