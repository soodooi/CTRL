Task-first discovery

U14 starts from the job, not an FCT name. Inline candidates keep the user in the current session; Library remains the comparison and cleanup surface.

One session control

“Use for this session” changes the next Irisy projection. It preserves Work Resources and resolves the FCT's Resources, optional Skill, policy, and gate scope before sending.

Trust and recovery

Choice, capture, and unavailable states are typed decision presentations. Targets, permissions, provenance, and recovery facts are shown without inventing outcomes in the frontend.
